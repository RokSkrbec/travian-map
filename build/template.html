Editor access
Anyone can view the plans. Saving writes plans.json into the GitHub repo, so editors need a GitHub token with write access to it. The token stays in this browser only.
  1. Repo owner: create a fine-grained token → Repository access: only RokSkrbec/travian-map → Permissions: Contents: Read and write.
  2. Other leaders: be added as a collaborator on the repo, then create a classic token with the public_repo scope (fine-grained tokens can't write to someone else's personal repo).
